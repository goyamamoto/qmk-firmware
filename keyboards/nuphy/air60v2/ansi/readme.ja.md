# NuPhy Air60 V2（ANSI）

> この文書は[英語版](./readme.md)の日本語訳です。内容が食い違う場合は英語版を正本とします。

* 保守: [goyamamoto](https://github.com/goyamamoto)
* 対象ハードウェア: NuPhy Air60 V2（ANSI）、USB `19F5:3255`

## このファームウェアの動機

Air60 V2 の純正ファームウェアは NuPhy 自身の QMK フォーク
（[nuphy-src/qmk_firmware](https://github.com/nuphy-src/qmk_firmware)）で、
2024 年の QMK で止まったまま更新されていません。
[ryodeushii](https://github.com/ryodeushii/qmk-firmware) のツリーは
`keyboards/nuphy/common` という共通層で NuPhy の無線機を最新の QMK に
追従させていますが、Air60 V2 は含まれていませんでした。この移植は
Air60 V2 をそのツリーに加えたもので、Air75 V2、Halo75 V2、Halo96 V2、
Gem80 と同じ保守された土台の上で動きます。

もう 1 つの動機は、日本語配列に設定されたホストで US 配列のキーボードを
使うことです。そのままではキーキャップの印字と入力される記号が一致しません。
以下の機能はこれをキーボード側で解決するもので、Keychron B1 Pro 向けの
[zmk-kb1-usjis](https://github.com/goyamamoto/zmk-kb1-usjis) と同じ振る舞いに
そろえています。

## 純正ファームウェアとの違い

| 問題 | このファームウェアの対応 |
|---|---|
| 純正 QMK は 2024 年のスナップショットで、更新の道筋がない。 | ryodeushii ツリーの現行 QMK 上に構築。無線、スリープ、デバウンス、VIA メニュー、RGB は他の NuPhy 機種と共有する共通層のもの。Air60 V2 固有なのはマトリクス、LED 表、サイドライトだけ。 |
| 日本語配列のホストでは `` ` ~ @ ^ & * ( ) _ = + [ { ] } \ \| : ' " `` が印字と違う記号になる。 | **US-JIS モード**（Fn+Tab）。この 20 個の入力を、印字どおりの文字を出す JIS 側の入力に置き換える。初期状態はオフ、設定は電源を切っても残り、OS スイッチが Win のときだけ効く。 |
| IME の切替は JIS キーボードなら専用キーがある。 | **スペース両隣の IME キー**。左をタップで IME オフ、右をタップで IME オン（Mac: 英数 / かな、Win: 無変換 / 変換）。押し続ければ従来どおり Cmd（Mac）/ Alt（Win）。 |
| 60% 配列では Ctrl が遠い。 | 両ベース層で **Caps Lock と左 Ctrl を入れ替え**。 |
| Win モードの 2.4 GHz / Bluetooth で JIS の `\` `_` `\|` が一切届かなかった。 | 共通層の不具合を修正。無線の NKRO 送信がキーコード 0x77 までしか運んでいなかった。 |
| OS 切替と Sleep 切替の点滅が左ストリップに出ていた（純正は右）。 | 純正どおり右ストリップに表示。 |
| LED ドライバが固まるとメインループが数秒止まりうる。 | I2C タイムアウトを 5 ms に設定（純正 1 ms、共通層の既定 100 ms）。 |
| 現行の VIA が純正の定義ファイルを受け付けない。 | VIA 定義を `qmk_rgb_matrix_keycodes` に更新し、全カスタムキーコードを列挙。 |
| 接続先と US-JIS の状態を一目で知る手段がない。 | **Fn 押下中の状態表示**。現在のリンクのキー（Q/W/E、R、Y）と、US-JIS 用に Tab が光る。RGB マトリクスがオフなら光らない。 |
| 共通層の充電アニメーションは高残量だと上段が点滅するだけで、サイドの表示がエフェクトとの競合でちらついた。 | 充電中は残量バーがその色のまま呼吸し、満充電は緑の静止バー。ストリップは RGB フレーム内でインジケータの下に描くので、ちらつかない。 |

それ以外（サイドライトのエフェクト、電池バー、スリープ、ペアリング、
VIA の照明メニュー）は共通層の他機種と同じです。

## キー操作

| キー | 動作 |
|---|---|
| Fn+Tab | US-JIS モードのオン / オフ。右ストリップが緑（オン）または赤（オフ）で点滅。`USJIS_ON` / `USJIS_OFF` キーコードと VIA のトグル（Custom Configs → Layout）もある。 |
| スペース左のキー | 押し続け: Cmd（Mac）/ Alt（Win）。タップ: 英数（Mac）/ 無変換（Win）= IME オフ。 |
| スペース右のキー | 押し続け: Cmd（Mac）/ Alt（Win）。タップ: かな（Mac）/ 変換（Win）= IME オン。 |
| Caps Lock 印字のキー | 左 Ctrl |
| Ctrl 印字のキー | Caps Lock |
| Fn+Q / W / E、Fn+R | Bluetooth 1〜3、2.4 GHz |
| Fn+M と矢印 / ; | サイドライトのモード、明るさ、色 |
| Fn 押下中 | 状態表示。現在のリンクを選ぶキーが光る（BLE1〜3 は Q/W/E が青、2.4 GHz は R が緑、USB は Y が白。無線で未接続なら点滅）。Tab は US-JIS の状態（ON で緑、OFF で赤）。RGB マトリクスがオフのときは何も光らない。 |
| Esc を押しながら USB 接続 | ブートローダー（DFU） |

OS スイッチでベース層が決まります。Mac（層 0、1、4）または Win（層 2、3、5）。
層 6 はサイドライト層（Fn+M）です。

### US-JIS モードの詳細

置換はキーを押した時点で、そのキーとそのときの Shift 状態から決まり、
離したときに押下時の判定どおりに戻します。置換キーを押している間、
レポートの Shift は最後に押したキーの要求に従うので、`@` の次に `A` を
押せば `@A` になります。Ctrl、Alt、GUI はそのまま通ります。キーを押している
最中のモード切替は、全部離すまで保留します。20 個の置換表と規則は
`keyboards/nuphy/common/core/usjis.c` にあります。

日本語配列に設定した Windows ホストで、有線と無線の両方で確認済みです。
置換キーを押したまま別のキーを押す操作（`=` の次に `A` で `=a`、`@` の
次に `A` で `@A`）は、実機と、その一連のレポートをすべて照合するホスト側
テストで確認済みです。
macOS では OS スイッチを Mac 側にしてください。macOS は US キーボードを
そのまま印字どおりに扱ううえ、このモードが `\` `_` `|` のために送る JIS の
キーコード（0x87、0x89）を捨てます。

### Windows での IME キー設定

Microsoft IME で無変換を「IME-オフ」、変換を「IME-オン」に割り当てます
（設定 → 時刻と言語 → 言語と地域 → 日本語 → Microsoft IME →
キーとタッチのカスタマイズ）。macOS は設定不要です。IME キーを押している
間に別のキーを押すと、即座にモディファイアとして扱われます
（`HOLD_ON_OTHER_KEY_PRESS`）。

## ビルドと書き込み

    qmk compile -kb nuphy/air60v2/ansi -km via

モードスイッチを有線側にし、Esc を押しながら USB を接続してブートローダーに
入れてから:

    dfu-util -a 0 -s 0x08000000:leave -D nuphy_air60v2_ansi_via.bin

QMK Toolbox でも書けます（[instructions.md](../../instructions.md)）。
nRF モジュールのファームウェアには触れず、Esc を押しながらの接続で
いつでもブートローダーに戻れるので、失敗しても書き直せます。

既定キーマップが変わったビルドを書き込んでも、VIA に保存されたキーマップが
優先されます。VIA の「Reset keymap」を実行するか、該当キーを変更してください。
VIA では Design タブから `keymaps/default/NuPhy Air60 V2 via3.json` を
一度読み込む必要があります。

## ハードウェア

* STM32F072、6×17 マトリクス（COL2ROW）、ピン配置は Halo75 V2 と同一
* I2C1 上の IS31FL3733 LED ドライバ 2 個: キー LED 64 個とサイド LED 10 個（index 64〜73、5 個ずつ 2 本）
* USART1 上の nRF モジュール（2.4 GHz と Bluetooth）

## サイドライト

エフェクトは両ストリップで動きます。左ストリップは Caps Lock と接続状態、
右ストリップは電池残量と、OS 切替 / Sleep / US-JIS の通知を表示します。
充電中は残量バーがその色のまま呼吸するので残量が読め、満充電になると緑の満タン静止バーになります。

Air60 V2 には F 行がないため、2 桁の値（デバウンス、スリープまでの時間、
数値の電池残量）は十の位を Q 行（Tab = 0、Q = 1 …）、一の位を数字行に
表示します。

## テストとエミュレータ

`keyboards/nuphy/air60v2/sim/` に、純正ファームウェアとの静的比較、
サイドライト・設定・US-JIS 置換のユニットテスト、そして仮想の STM32F072 上で
ファームウェアを起動し偽の nRF モジュール経由でキーを打つ Renode
エミュレータがあります。[sim/README.md](../sim/README.md) を参照してください。

## 共有コード

この機種は `keyboards/nuphy/common` を使います。機種固有ファイルが持つのは
マトリクス走査、LED 表、サイドライト、キーボードのメタデータです。この機種の
ために共通層に加えたもので他機種でも使えるのは、US-JIS 置換とそのキーコード、
2 本ストリップ向けの `set_notice_on_side()`、`CAPS_LOCK_ROW` /
`CAPS_LOCK_COL`、`NUPHY_TENS_DIGIT_ROW` です。
